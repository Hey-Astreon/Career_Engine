# Fundamental Planning Directive

**CRITICAL RULE FOR ALL FUTURE TASKS:**

Before executing any code changes or proceeding with a feature implementation, you MUST:
1. **Think**: Analyze the user's request deeply.
2. **Visualize**: Mentally map out the UI/UX, the architecture, and how the data flows.
3. **Count the Outcomes**: Anticipate edge cases, side effects, and all possible outcomes of the proposed solution.
4. **Create the Masterplan**: Only after steps 1-3 are complete, draft a concrete, step-by-step implementation plan (a "masterplan").

Do NOT proceed blindly. Always pause to align on the masterplan with the user if the feature is complex.
