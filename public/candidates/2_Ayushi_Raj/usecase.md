# Decision Tree

### If the job description mentions:
> AI, LLMs, GenAI, Copilot, AI Agent, Prompt Engineering, Gemini, OpenAI, Anthropic, LangChain, AI Platform  
> **→ Use Resume A**

### If the job description mentions:
> Software Engineer, Backend, Java, Spring Boot, FastAPI, REST APIs, Database, System Design, Platform  
> **→ Use Resume B**

### When uncertain:
*   **YC Startup** → Resume A
*   **AI Startup** → Resume A
*   **Traditional Software Company** → Resume B
*   **Enterprise** → Resume B
*   **FinTech Startup** → Resume A
*   **Product Company** → Choose the resume that best matches the job description.
