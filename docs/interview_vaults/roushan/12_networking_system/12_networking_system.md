# Networking & Referral Operating System

Structured framework for proactive recruiter and engineer networking.

---

## 1. Outreach Playbook
*   **Target Persona 1:** Senior Backend Engineers / Tech Leads at target companies.
*   **Target Persona 2:** Technical Recruiters sourcing software engineering roles.
*   **Target Persona 3:** YC Startup Founders.

---

## 2. Cold Outreach Message Structure
1.  **Hook:** Mention a specific project or engineering topic (`CommBank .NET simulation`, `Tree-Sitter AST parser`, `Web Crypto zero-knowledge manager`).
2.  **Value Pitch:** Briefly outline technical strengths (C#/.NET, FastAPI, automated test suites).
3.  **Call to Action:** Ask for a 10-minute introductory call or referral.
