# Project Interview Kit: CommBank Software Engineering Simulation
**Project:** Commonwealth Bank Enterprise C#/.NET Backend Refactoring  
**Tech Stack:** C#, .NET Core Web API, MongoDB, React.js, Redux, xUnit, Moq

---

## 1. Project Summary
Enterprise backend simulation extending CommBank API services, patching MongoDB endpoints for partial updates, and authoring automated test suites.

## 2. Engineering Achievements
*   Patched MongoDB endpoints using `$set` operations for partial payload updates, preventing silent data overwrites.
*   Authored comprehensive xUnit unit tests using Moq for dependency mocking, achieving 100% test coverage across controllers.
*   Built React/Redux Goal Manager component to handle state flow across banking dashboards.
