# Company Research & Pre-Interview Framework

Template for evaluating target companies before applying or interviewing.

---

## Research Template
*   **Company Name:** [Name]
*   **Domain & Product:** [Product area, e.g., Cloud SaaS / AI Dev Tools]
*   **Tech Stack:** [e.g., .NET / Python / React / PostgreSQL]
*   **Engineering Culture:** [e.g., Test-driven, rapid shipping, remote-first]
*   **Key Projects to Highlight:** [e.g., CommBank .NET simulation for backend / Astra Vision for AI roles]
*   **Questions to Ask Interviewer:**
    1.  *What does the backend API architecture look like for your core microservices?*
    2.  *How does your team handle automated testing and CI/CD validation?*
    3.  *How are AI developer tools integrated into your daily workflow?*
