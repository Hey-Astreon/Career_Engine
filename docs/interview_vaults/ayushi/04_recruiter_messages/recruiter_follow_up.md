# Recruiter Follow-up Templates
**Usage:** Send to recruiters or hiring managers to check application status or follow up after an interview.  
**Placeholders:** `[Company Name]`, `[Job Title]`, `[Recruiter Name]`, `[Interview Round]`

---

### Template 1: Post-Application Follow-up (7-10 Days Post-Apply)
*Use to prompt a response on an active application without using generic phrases.*

> Subject: Application Status: [Job Title] – Ayushi Raj
> 
> Hi [Recruiter Name],
> 
> I submitted my application for the [Job Title] role at [Company Name] last week, and wanted to follow up.
> 
> I’m an AI-Powered Full Stack Software Engineer. I specialize in secure web applications and backend APIs, with experience building zero-knowledge cryptographic platforms (Alyra Lock) and Fastify/FastAPI routing gateways (IDBI FinSync / Axiom AI). I am confident that my technical background aligns with the engineering needs for this role.
> 
> I've attached my resume here. Please let me know if there are any other code samples or details I can provide to assist in your review.
> 
> Thank you,  
> Ayushi Raj  
> ayushi29507@gmail.com | [github.com/Silenttears-cloud](https://github.com/Silenttears-cloud)

### Template 2: Post-Interview Status Update (7 Days Post-Interview)
*Use if the recruiter promised an update by a certain date and that date has passed, or if it has been 7 days since the interview.*

> 
> Please let me know if you need any further references or code samples from my side.

> Ayushi Raj
